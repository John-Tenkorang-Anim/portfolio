# Resume Folder

Place your resume PDF file here with the name: `John_Tenkorang_Anim_Resume.pdf`

The resume download button on your portfolio will automatically link to this file.

## Instructions:
1. Export your resume as a PDF
2. Rename it to: `John_Tenkorang_Anim_Resume.pdf`
3. Place it in this folder (`/public/resume/`)
4. The navbar Resume button will now download your PDF instead of linking to LinkedIn
