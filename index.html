02 ~/research

Research

Under review Manuscript · OpenReview

Trace2RLE: From Agent Traces to Stateful Reinforcement-Learning Environments

A nonintrusive framework that turns historical execution traces into a stateful RL environment for any tool set, without training a world model.

Read the abstract

LLM agents are increasingly used in real world industry workflows and as personal assistants. To help these agents master domain specific tools, reinforcement learning (RL) is essential. However, training directly with real tools is rarely feasible: third party services such as payment systems cannot be used during training, tool operations may cause irreversible side effects, and even building simulated environments with real tools requires extensive engineering work. Existing simulation alternatives either require manual server coding or rely on training expensive world models, which may not generalize to new tools unseen during training. In contrast, we propose Trace2RLE, a nonintrusive framework that turns historical execution traces into a stateful RL environment for any tool set without training a world model. When the agent calls a tool during training, Trace2RLE retrieves similar past calls from logs and uses them to guide an LLM to generate realistic tool outputs and update the session state across turns. On τ²-bench, RL training in Trace2RLE achieves a 0.961 reward on the real backend, matching direct training with real tools and showcasing its effectiveness as a practical, scalable replacement for real tool environments.
